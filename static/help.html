教学排课管理系统 · 使用帮助

网页排课Excel 导入导出钉钉机器人填报钉钉日程 / 待办研究生汇报题目

1三种使用身份，各做各的事

身份能做什么身份如何被识别
管理员 / 教学秘书 网页端全部功能：名单管理、生成 / 导入 / 发布课表、排课规则、钉钉配置 系统登录账号（管理员分配）
带教老师 网页端查课表；钉钉群里查课、填课程名、请假、建提醒 / 待办 「教师管理」里登记的手机号 = 钉钉绑定号
研究生汇报人 钉钉群里查本人汇报、填报 / 修改汇报题目 「研究生管理」里登记的手机号 = 钉钉绑定号
核心原则：机器人靠手机号认人。手机号没登记或与钉钉不一致，就会提示「未识别到您的身份」——这是绝大多数机器人问题的原因。

2网页端：一个月课表的标准流程

1
排课规则（只需设置一次）：每天节数、每节课型顺序（标签可拖动箭头换序）、上课时间、每人每月次数上限。
2
生成课表 → 生成草稿：系统按规则自动排人，避开请假、避开冲突、均衡负荷。
3
点格子微调：点击任意课程格，就地修改老师 / 主阅 / 评审 / 指导（支持输入拼音首字母、粘贴「姓名(工号)」快速选中）。
4
发布并推送钉钉：发布后自动给相关老师建钉钉日程 / 待办，机器人随即可以填报课程名。
5
导出 Excel：单月「导出Excel」或整年「导出全年」（一个工作表按月分块，改完可直接再导入）。

用 Excel 导入课表（推荐首次建表时用）

  • 先「下载导入模板」，按模板填写；也接受自己排的表（表头含 日期 / 课程 / 节 / 老师等即可）。
  • 支持全年文件：按每行日期自动分月导入，不用按月拆表。
  • 勾选「自动新增名单外人员」：老师列的新名字自动进教师表，主阅列的新名字自动进学生表（只增不改，已有的人绝不覆盖）。
  • 合并模式 = 同日同节更新；覆盖模式 = 清空文件涉及的每个月重建（红色提示，慎用）。
  • 导入前会先出预览：逐行列出新增 / 更新 / 错误，确认无误再执行。
科里有两位「王晓」？在「教师管理」给两人分别填别名（如 王晓1、王晓2），导入文件和人员选择器就都能准确区分，系统不会自作主张猜人。

3名单管理：信息越全，排课越省心

页面关键字段影响
教师管理 可讲课 / 可主阅 / 可评审 / 可指导；别名；请假日期；手机号；启用/停用 自动排课的人选池；「可指导」决定谁会被排为指导老师；手机号用于钉钉身份与日程；停用的老师（进修/离职等）不再参与自动排课、不出现在人员选择名单，历史课表不受影响，可随时再启用
学生管理 学号、姓名、年级 主阅轮转的人选池
研究生管理 编号、姓名、专业、手机号；支持「从教师 / 学生导入」一键勾选 第三节「研究生汇报」的汇报人轮转；手机号用于机器人填报题目
节假日 停课日期 生成课表时自动跳过

教师 / 学生 / 研究生名单都支持 Excel 导入导出，改完名单回导即可批量更新。

4钉钉机器人指令大全

在教学群里 @机器人（或私聊机器人）发送指令。发「帮助」可随时查看。

4.1 所有人都能用

指令说明
今天 / 明天全院当日 / 次日课表（无需登记手机号）

4.2 老师指令

指令说明
列表本人待填课程名的课
12-03 小讲课题目内容给 12 月 3 日自己讲的课填课程名
改 12-03 新课程名修改已填的课程名
课表 12月 / 本周 / 下周本人课程安排（讲课 / 主阅 / 评审 / 指导全覆盖）
提醒 12-05 14:00 技能考核在本人钉钉日历建日程（时间可省略，默认 09:00）
待办 12-05 提交出科考核表给本人建钉钉待办（默认当天 18:00 截止）
请假 12-03 或 请假 12-03 至 12-05登记请假，下次排课自动避开
销假 12-03取消某天请假
催办列出还没填课程名的课并 @ 相关老师（管理员用）

4.3 研究生汇报人指令

指令说明
列表本人待填报题目的汇报场次
12-03 肺结节影像诊断给 12 月 3 日本人的汇报填题目（也支持 12月3日、12.3）
改 12-03 新题目修改已填的题目（已填过直接重发会被拦截，防止误覆盖）
课表 12月 / 本周 / 下周本人汇报安排与题目状态
题目填好后自动同步：网页端课表即时可见，汇报人钉钉日历上的日程标题同步更新。题目只能由汇报人本人填，替别人填会被拒绝。

4.4 课表发布后自动发生的事

  • 每位相关老师的钉钉日历自动创建课程日程（含时间、课程名、角色）。
  • 临期课程提前推送钉钉待办提醒（可在「钉钉配置」里设提醒天数）。
  • 研究生汇报节日程挂在汇报人日历上，题目更新后自动改标题。

5常见问题

现象原因与解决
机器人回复「未识别到您的身份」 「教师管理 / 研究生管理」里的手机号没填，或与钉钉绑定号不一致。改好后等约 10 分钟缓存刷新（或让管理员重启服务立即生效）。
导入报「查无此人」 名单里没有这个人。勾选导入弹窗的「自动新增名单外人员」，或先在名单管理里补录。
导入报「缺少老师」 教学阅片 / 病例讨论等课型本来就由主阅负责，老师列允许留空，新版会作为警告正常导入。
两位同名老师分不清 「教师管理 → 编辑 → 别名」分别填不同称呼（如 王晓1 / 王晓2），导入与选择器按别名精确匹配。
想交换「教学阅片 / 病例讨论」的先后 「排课规则 → 课型编排」：点课型标签的左右箭头换序，保存后重新生成该月。已生成的旧课表不会自动变。
老师列的课显示「-」 多为历史演示数据引用了已删除的老师，重新生成 / 导入该月即可。
没收到钉钉日程 ① 本人手机号未登记或不一致；② 课表尚未发布；③ 「钉钉配置」里日历同步未开启。
误填了课程名 / 题目 发 改 12-03 正确内容 覆盖；或让管理员在网页端直接修改。
第二个钉钉群也想收课表 每个群各自「群设置 → 机器人 → 添加机器人 → 自定义」拿 Webhook；管理员在「钉钉配置 → 其他钉钉群」里添加该群并勾选「启用推送」，发布时两个群同时收到。取消勾选即停用。
学生毕业了，历史课表怎么办 直接在「学生管理」删除即可。每节课都保存了当时的名字快照，历史课表、导出 Excel、钉钉推送里的名字不会变空白；只有删除前就没排过课的情况无影响。毕业生对应的登录账号会一并删除。

6遇到解决不了的问题

  • 网页端数据问题（排错人、课表错了）：联系教学秘书在「生成课表」里点格子修改或重新生成。
  • 账号 / 权限：联系系统管理员在「用户管理」里开通。
  • 钉钉推送异常：管理员检查「钉钉配置」页的连接状态，点「测试」验证。
